# Excel Data Analysis & Manufacturing Dashboards

## Overview

This repository contains Excel-based data analysis and dashboard projects focused on manufacturing, production planning, production tracking, yield analysis, cost analysis, inventory-related planning, and operational reporting.

These projects demonstrate practical use of Microsoft Excel to transform operational data into structured reports, KPIs, dashboards, summaries, and business insights.

> **Note:** The files in this portfolio should use sanitized/demo data and must not contain confidential company information.
